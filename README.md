# 🌟 Smart Mood Calculator

A unique and modern calculator application developed using Python and Tkinter as part of the CodSoft Python Programming Internship.

## 📌 Project Description
Smart Mood Calculator is not just a normal calculator.  
It performs arithmetic calculations and also gives smart mood-based responses depending on the result.  
The application features a futuristic dark-themed GUI, calculation history, dynamic colors, and keyboard support.

---

## 🚀 Features
- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🎨 Modern Dark-Themed GUI
- 😊 Smart Mood Messages
- 📜 Calculation History
- ⌨ Keyboard Support
- ⚠ Error Handling
- 🌈 Dynamic Color Effects
- ⌫ Backspace Function
- 🕒 Live Date & Time

---

## 🛠 Technologies Used
- Python
- Tkinter
